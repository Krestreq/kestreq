# KrestReq

**Build. Test. Debug. Locally.**

KrestReq is an open-source, offline-first desktop API testing client designed for developers who want a fast, reliable, and modern environment to develop, test, and debug HTTP APIs.

Built with **Tauri 2, React, TypeScript, and Express.js**, KrestReq aims to simplify API development through a clean desktop interface, powerful request management, response inspection, authentication support, and automated API testing.

### Why KrestReq?

- Test REST APIs with ease.
- Work with local and remote APIs.
- Organize requests into collections.
- Manage authentication and environment variables.
- Inspect HTTP responses and debug API issues.
- Store requests and history locally.
- Work without requiring a cloud account.

### Technology Stack

- Tauri 2
- React
- TypeScript
- Vite
- Express.js
- Axios
- SQLite
- Rust
